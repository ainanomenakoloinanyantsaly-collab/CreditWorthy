# CreditWorthy – Agricultural Credit Scoring Platform

## Project Overview

CreditWorthy is an AgriTech platform that transforms agricultural data into an intelligent credit scoring system to support financial inclusion for farmers. It enables banks and investors to assess creditworthiness using agricultural production data instead of traditional banking history.

The system helps connect underserved farmers to financial institutions by providing data-driven risk evaluation and loan estimation tools.

---

## Problem Statement

In many countries such as Madagascar and across Africa, farmers often lack:
- formal banking history
- payslips or financial records
- access to traditional credit systems

As a result, many farmers are excluded from financial services, and banks face difficulties assessing their credit risk.

---

## Solution

CreditWorthy proposes an alternative credit evaluation system based on agricultural data.

Farmers input:
- region
- crop type (rice, vanilla, maize, etc.)
- land size
- estimated yield
- financial access level

---

## System Analysis

The platform analyzes:
- estimated crop value
- climate compatibility
- production stability
- financial profile

---

## Output

The system generates:
- credit score
- estimated loan amount
- risk category (A, B, C)

This helps financial institutions:
- identify reliable borrowers
- reduce lending risk
- improve agricultural investment decisions

---

## Impact

CreditWorthy aims to:
- improve financial inclusion
- support small-scale farmers
- reduce risk for lenders
- increase agricultural investment
